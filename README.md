# Konsole Lite · Schulung

Öffentliche Schulungsunterlagen und interaktive Browser-Lernmodelle für Servicetechniker.

Das Softwareprojekt bleibt separat und privat. Dieses Repository enthält keine Editor-, PLC- oder Maschinensteuerungsquellen.

## Lernweg

- Basic: zwei Tage Oberflächengestaltung im QML Editor.
- Fortgeschrittene: zwei Tage Grundtypen, Units, Schrittketten und LOCAL-Diagnose.

Die Website wird als statische HTML-/CSS-/JavaScript-Seite für GitHub Pages vorbereitet. Lernmodelle haben keine PLC-Anbindung. Der Kursstand und noch nicht ausgearbeitete Abschnitte werden ausdrücklich gekennzeichnet.
